# Piano photos

Drop photos you like here: full size, original files, any names.

- Not served by the site. Claude picks from this folder and exports optimised
  versions (resized, WebP/AVIF) into the app only for images that get used.
- Note in the filename if a photo should be dark or light, e.g.
  `roland-evening-dark.jpg`, `keys-window-light.jpg` (optional).
- Only use photos you took or have the rights to use.
